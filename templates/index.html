Developer API

GET /search

Search for tracks and get their lyrics availability.

Limit: 60 requests / minute

Parameters

Name Type Description
query string The search term (track/artist)
limit number Max results (default: 10)
offset number Pagination offset (default: 0)

Example Response

{
  "results": [
    {
      "id": "a1b2c3d4e5f6g7h8...",
      "track": "Song Name",
      "artist": "Artist Name",
      "album": "Album Name",
      "duration": 215,
      "lyrics": {
        "plain": "Lyrics...",
        "synced": "[00:00.00]...",
        "karaoke": "[00:00.00] <00:00.05>..."
      }
    }
  ],
  "total": 1,
  "limit": 25,
  "offset": 0
}
GET /lyrics

Fetch lyrics for a specific track.

Limit: 300 requests / minute

Parameters

Name Type Description
track string Track name
artist string Artist name
type string plain / synced / karaoke

Example Response

{
  "id": "a1b2c3d4e5f6g7h8...",
  "lyrics": "[00:12.34] Hello world...",
  "type": "synced"
}
