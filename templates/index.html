Developer API

You can use the SyncLRC API to fetch lyrics programmatically.

Endpoint

GET /lyrics

Parameters

  • id (Optional): Unique hash to fetch specific lyrics (bypasses track/artist).
  • track (Required if no id): Name of the song.
  • artist (Required if no id): Name of the artist.
  • type (Optional): karaoke, synced, or plain.

Example Requests

Fetch by track/artist:

/lyrics?track=Song&artist=Artist&type=synced

Fetch by unique ID:

/lyrics?id=a1b2c3d4e5f6g7h8...

Response Format

{
  "id": "a1b2c3d4e5f6g7h8...",
  "track": "Song Name",
  "artist": "Artist Name",
  "lyrics": "[00:00.00]...",
  "type": "synced"
}
