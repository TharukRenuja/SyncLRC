Developer API

GET api.synclrc.dev/search

Search for tracks and get their lyrics availability.

Limit: 30 requests / minute

Parameters

Name Type Description
q string (Required) Search term
limit number (Optional) Max results (default: 10)
offset number (Optional) Results offset (default: 0)

Example Response

{
  "results": [
    {
      "id": "a1b2c3d4e5f6g7h8...",
      "track": "Song Name",
      "artist": "Artist Name",
      "album": "Album Name",
      "duration": 215,
      "instrumental": false,
      "lyrics": {
        "plain": "Lyrics...",
        "synced": "[00:00.00]...",
        "karaoke": "[00:00.00] <00:00.05>..."
      }
    }
  ],
  "total": 1,
  "limit": 10
}
GET api.synclrc.dev/lyrics

Fetch lyrics for a specific track.

Limit: 30 requests / minute

Parameters

Name Type Description
track string (Required) Song name
artist string (Required) Artist name

Optional Parameters

Name Type Description
type string Filter by format: karaoke, synced, or plain
album string Album name (improves matching)
duration number Track duration in seconds (improves matching)

Example Response

{
  "id": "a1b2c3d4e5f6g7h8...",
  "track": "Song Name",
  "artist": "Artist Name",
  "album": "Album Name",
  "duration": 215,
  "instrumental": false,
  "karaoke": "[00:00.00] <00:00.05>...",
  "synced": "[00:00.00]...",
  "plain": "Lyrics..."
}
GET api.synclrc.dev/lyrics/{id}

Fetch lyrics by the track's canonical ID (returned by search or lyrics endpoints).

Limit: 30 requests / minute

Parameters

Name Type Description
id string (Required) 32-character hex canonical ID
type string (Optional) Filter by format: karaoke, synced, or plain

Example Response

{
  "id": "a1b2c3d4e5f6g7h8...",
  "track": "Song Name",
  "artist": "Artist Name",
  "album": "Album Name",
  "duration": 215,
  "instrumental": false,
  "karaoke": "[00:00.00] <00:00.05>...",
  "synced": "[00:00.00]...",
  "plain": "Lyrics..."
}
